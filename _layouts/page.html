What `full:` picks is what happens INSIDE it: default prose capped at the reading measure (.container-ideal on the
), centred — 22 pages rely on this: about's prose ancestors, books, contact, blogroll, styleguide, 404, … full: true content fills the standard width — for pages that lay themselves out, like /about/'s timeline. ⚠️ `full:` no longer means "full-bleed". It did when `main` was unbounded; `main` is capped at --body-width-max now, so `full: true` gets the standard band, not the viewport. Renamed in spirit, not in key, because the key has a user (about.html).
