## Useful Techniques for User-Friendly Tables

UX Movement lists [9 great techniques for a User Friendly Table design](https://uxmovement.com/content/useful-techniques-for-user-friendly-tables/). Some of the one that I really like -- Tool Tips for Exact Values, Persistent Column Headers, Invert Arrows for Columns and of course Zebra Stripes.

## The top 10 open source web fonts

Micah Rich, co-founder of The League of Moveable Type, rounds up the [best open source fonts](https://www.netmagazine.com/features/top-10-open-source-web-fonts) for web design and explains how you can contribute. He looks at the precursors to the @font-face revolution, Google Web Fonts and fonts from [the League](https://www.theleagueofmoveabletype.com/).

## Document outlines in HTML5

The HTML5 Doctor explains [what document outlines are](https://html5doctor.com/document-outlines/), how to make good ones, and why you should care.
